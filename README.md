## Problem Statement

The objective of this project is to segment customers based on their annual income and spending behavior using K-Means clustering.

## Dataset

Mall Customers Dataset containing customer information such as age, gender, annual income, and spending score.

## Approach

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Selection
- Feature Scaling using StandardScaler
- Elbow Method for selecting the number of clusters
- K-Means Clustering
- Customer Segment Analysis
- Business Insights

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Git & GitHub

## Results

Customers were segmented into 5 groups based on annual income and spending score.
